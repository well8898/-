# 오늘 현장 위젯 (안드로이드)

홈 화면 위젯에 오늘(18시 이후엔 다음 근무일) 현장 목록을 보여 주고,
줄이나 「티맵」을 누르면 그 현장으로 티맵 길안내를 연다.
데이터는 웹앱의 개인 위젯 주소(`…/exec?w=키`) JSON을 30분마다(또는 제목 탭) 받아 온다.

- 빌드: 푸시하면 `.github/workflows/build-widget-apk.yml` 이 APK를 만들어
  릴리스 `widget-apk` 에 `schedule-widget.apk` 로 올린다.
- 설치: 휴대폰에서 릴리스 페이지의 APK를 받아 설치 → 앱에서 위젯 주소 붙여넣기 → 저장 → 위젯 추가.
- `app/widget.keystore` 는 업데이트를 덮어 설치하기 위한 고정 서명 키(개인 사이드로드용).
- 개인 위젯 주소는 앱 안에만 저장되고 APK에는 들어가지 않는다.
