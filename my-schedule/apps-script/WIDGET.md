# 홈 화면 위젯 A안 만들기 (KWGT)

웹앱 「홈 화면 위젯 주소」의 **JSON 주소**를 아래 `주소` 자리에 넣으세요. (따옴표 안)

## 웹앱이 주는 항목

| 항목 | 내용 | 예 |
|---|---|---|
| `.title` | 제목 | 오늘 10/16(금) · 15조 |
| `.sub` | 요약 | 5곳 · 6대 · 24.0km · 동행 조현준 |
| `.updated` | 마지막 저장 | 10/16 07:52 |
| `.h1`~`.h8` | 현장 시간 | 09:30 |
| `.n1`~`.n8` | 현장명 | 동주오피스텔 |
| `.s1`~`.s8` | 동 · 종류 대수 | 주엽동 · 정기 2 |
| `.d1`~`.d8` | 지난 현장이면 1 | 1 / 0 |
| `.t1`~`.t8` | 티맵 길안내 링크 | |
| `.k1`~`.k8` | 카카오 길찾기 링크 | |
| `.rk` | 하루 경로 (카카오) | |

현장이 없는 번호는 빈칸으로 옵니다.

## 만들기

1. 홈 화면 길게 누르기 → 위젯 → **KWGT 4×3** 놓기 → 위젯 눌러 편집 열기
2. 배경: 최상단 레이어 → **배경 색** 어두운 반투명(예 `#DD121822`), 모서리 둥글게
3. **+ → 텍스트** 2개 (맨 위)
   - 제목: `$wg("주소", json, .title)$` (굵게, 15)
   - 요약: `$wg("주소", json, .sub)$` (회색, 12)
4. **+ → 겹침 그룹(Overlap Group)** 하나 만들고 이름을 `줄1`로 (현장 1번 줄)
   - 안에 **도형(사각형)**: 가로 꽉, 세로 44, 모서리 14, 색 `#10FFFFFF` (줄 배경)
   - **텍스트** 시간: `$wg("주소", json, .h1)$` (왼쪽, 굵게)
   - **텍스트** 현장명: `$wg("주소", json, .n1)$` (시간 오른쪽, 굵게 14)
   - **텍스트** 작은 글: `$wg("주소", json, .s1)$` (현장명 아래, 회색 11)
   - **도형+텍스트** 「티맵」 버튼: 오른쪽 끝, 파란색 `#4B8DF8`
     - 버튼의 **터치 → 동작: 링크 열기(Open link)** → `$wg("주소", json, .t1)$`
   - 지난 현장 흐리게: `줄1` 그룹의 **레이어 → 투명도(Alpha)**에 수식 `$if(wg("주소", json, .d1)=1, 45, 100)$`
   - 현장이 없는 날 숨기기: `줄1` 그룹의 **레이어 → 보이기(Visible)**에 `$if(wg("주소", json, .n1)="", REMOVE, ALWAYS)$`
5. `줄1`을 **복제**해 `줄2`~`줄8`을 만들고, 수식 속 번호만 바꾸기 (`.h1`→`.h2`, `.n1`→`.n2`, `.s1`→`.s2`, `.t1`→`.t2`, `.d1`→`.d2` …)
   - 묶어서 세로로 쌓으려면 줄들을 **스택 그룹(Stack Group, 세로)** 안에 넣기
6. 맨 아래 버튼 2개
   - 「하루 경로 · 카카오」: 터치 → 링크 열기 → `$wg("주소", json, .rk)$`
   - 「웹앱 열기」: 터치 → 링크 열기 → 웹앱 주소(`?w=` 앞까지)
7. 오른쪽 위 💾 저장

## 새로 고침

- KWGT는 받아 온 내용을 잠시 저장해 둡니다. 설정 → **고급 → 업데이트 간격**을 15~30분으로.
- 바로 바꾸고 싶으면 KWGT 앱을 열거나 위젯 편집에 들어갔다 나오기.
- 웹앱에서 새 일정표를 올리면 다음 새로 고침 때 바뀝니다.
