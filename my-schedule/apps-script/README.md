# 내 검사 일정 — 지도·이동거리 버전 (별도 Apps Script 웹앱)

여비 청구 웹앱과는 **완전히 별개인 새 Apps Script 프로젝트**로 만듭니다. 여비 청구 쪽 파일·설정은 건드리지 않습니다.

이 버전은 claude.ai 링크 버전 화면에 다음이 더해집니다.
- 하루 보기: 카카오 지도에 방문 순서 번호 핀 (지사 출발·도착 포함)
- 출발 지사: 일정표 제목 → 지난번 선택 → 현장 동네로 추측 순으로 정하고, 화면에서 바꿀 수 있음.
  현장 위치는 그 지사에서 50km 안의 검색 결과만 씀 (관할 지역 밖에 핀이 찍히지 않게)
- 구간별 이동거리(자동차 추천경로, 카카오모빌리티)와 합계, "경로·거리 복사" 버튼
- 주소가 없거나 위치를 못 찾은 현장은 지도·거리 계산에서 빠짐

## 만들기 (한 번만)

1. https://script.google.com → **새 프로젝트**. 이름은 `내 검사 일정`.
2. 기본으로 있는 `Code.gs` 내용을 지우고 이 폴더의 `Code.gs`를 붙여 넣기.
3. 화면(`Index.html`)은 `Code.gs`가 GitHub에서 바로 읽어 오므로 붙여 넣지 않아도 됩니다.
   (GitHub를 못 읽는 환경일 때만 파일 추가(＋) → HTML → 이름 `Index`로 만들어 붙여 넣기)
4. ⚙ 프로젝트 설정 → **스크립트 속성**에 추가
   | 속성 | 값 |
   |---|---|
   | `KAKAO_REST_API_KEY` | 카카오 REST API 키 |
   | `KAKAO_JS_KEY` | 카카오 JavaScript 키 |
5. 편집기에서 함수 `testSetup` 선택 → ▶ 실행 → 권한 허용. 로그에 좌표가 나오면 키가 맞는 것.
6. **배포 → 새 배포 → 웹 앱**, 실행: 나, 액세스: 나만(또는 원하는 범위) → 배포. 나온 웹앱 주소를 휴대폰 홈 화면에 추가.
7. 웹앱을 열고 일정표를 올린 뒤 하루 보기를 눌렀을 때 지도가 안 나오면, 화면에 나온 도메인을
   카카오 디벨로퍼스 → 내 애플리케이션 → 플랫폼 → **Web 사이트 도메인**에 추가.

카카오 앱에서 **카카오맵**(장소 검색)과 **카카오모빌리티 길찾기** API가 켜져 있어야 합니다.

## 화면 고치기

화면은 GitHub의 `my-schedule/apps-script/Index.html`에서 읽어 오므로, 그 파일이 바뀌면 웹앱도 10분 안에 바뀝니다(재배포 불필요).

`Index.html`은 `my-schedule/index.html`(claude.ai 링크 버전)과 같은 화면입니다.
그 파일 `<style>` 끝까지를 `<head>`에, 나머지를 `<body>`에 넣어 만듭니다.
지도·거리 기능은 Apps Script 웹앱으로 열었을 때만 켜집니다.

## 현장 실주소 찾는 순서

1. 승강기검사접수정보 API (정밀·설치·수시) — 스크립트 속성 `DATA_GO_KR_KEY` 필요
2. 건물 주소록 `my-schedule/data/bld/*.json` (승강기 설치 현황 CSV에서 건물명→주소, 정기 포함 전체)
   - 새 CSV가 나오면 `python3 my-schedule/tools/build_bld.py 파일1.csv 파일2.csv my-schedule/data/bld` 로 다시 만들어 올리면 됨 (건물명·건물주소 열)
3. 카카오 장소 검색 (동 + 건물명, 지사 50km 안)

## 브랜치

웹앱(Code.gs)은 화면(Index.html, Index 파일이 없을 때)과 건물 주소록을 GitHub **`my-schedule` 브랜치**에서 읽습니다.
이 브랜치는 지우거나 이름을 바꾸지 마세요. 일정 페이지를 고치면 이 브랜치에도 같이 올립니다.
